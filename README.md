# Saurabh Jawalekar Portfolio — V5

Production-oriented Next.js portfolio for an Enterprise Solution Architect.

## V5 changes
- Migrated the portfolio concept to Next.js App Router + TypeScript.
- Data-driven work/case-study routes.
- Interactive architecture playground.
- Architecture-first positioning rather than a generic developer portfolio.
- Added an **Engineering Archive** based on Saurabh Jawalekar's older public WordPress material:
  - SharePoint 2013 Workflow Manager installation/configuration (2018)
  - Metalogix vs ShareGate vs AvePoint migration tooling comparison (2018)
  - SharePoint community problem solving
- Preserves a confidentiality-safe boundary around current enterprise work.
- SEO metadata + Open Graph foundation.
- Responsive design, mobile navigation and light/dark theme.

## Run
npm install
npm run dev

## Build
npm run build
npm start

Deployable to Vercel or Azure Static Web Apps after adding the preferred CI/deployment configuration.
