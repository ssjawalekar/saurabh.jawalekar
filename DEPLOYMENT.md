# Deployment

## Vercel
1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Framework preset: Next.js.
4. Build command: `npm run build`.

## Azure Static Web Apps
Use the standard Next.js deployment workflow. For a production deployment, connect the repository and set the app location to `/`, then use the generated Next.js build configuration.

## Local
`npm install`
`npm run dev`
